## 인터랙션 정의

| 요소 | 동작 |
|------|------|
| 탭 전환 | URL 쿼리 변경 (`?tab=sensor`) |
| [연결 테스트] 버튼 | Modbus 통신 테스트 API 호출, 결과 인라인 표시 |
| [베이스라인 재학습 시작] | 확인 모달 후 학습 API 트리거 |
| ISO 기준값 자동 적용 | 선택된 ISO 등급에 따라 입력 필드 자동 채우기 |
| [+ 수신자 추가] | 이메일 입력 + 알림 조건 선택 인라인 폼 |
