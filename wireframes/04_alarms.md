## 필터 드롭다운 옵션

| 필터 | 옵션 |
|------|------|
| 유형 | 전체 / 경보 / 주의 / 정보 / 센서오프라인 |
| 모터 | 전체 / 컴프레서 #1~3 / 펌프 #1~2 / 환풍기 #1 |
| 상태 | 전체 / 미확인 / 확인됨 / 해결됨 |
| 기간 | 오늘 / 최근 7일 / 최근 30일 / 사용자 정의 |

---

## 인터랙션 정의

| 요소 | 동작 |
|------|------|
| 알람 행 클릭 | 해당 행 확장 (상세 내용 표시) |
| [모터 상세] 버튼 | `/motors/[id]` 이동 |
| [확인] 버튼 | 확인 처리 모달 열기 |
| [해결됨] 버튼 | 해결 처리 (확인된 알람만 활성화) |
| 미확인 N건 배지 | 미확인 필터 자동 적용 |
