## 인터랙션 정의

| 요소 | 동작 |
|------|------|
| 브레드크럼 `← 대시보드` | 대시보드로 뒤로 이동 |
| 트렌드 탭 | RMS/온도/HF/Kurtosis 차트 전환 |
| 기간 선택 | 차트 데이터 범위 변경 |
| FFT 주파수 마커 | 클릭 시 해당 성분 설명 툴팁 |
| [정비 기록 추가] 버튼 | 정비 모달 열기 |
| [전체보기] 정비 이력 | `/maintenance?motor=[id]` 이동 |
