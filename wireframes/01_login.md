## 상태별 처리

| 상태 | 동작 |
|------|------|
| 로그인 성공 (일반) | 대시보드(`/`)로 이동 |
| 로그인 성공 (최초) | 비밀번호 변경 화면으로 이동 |
| 로그인 실패 | "아이디 또는 비밀번호가 올바르지 않습니다" 인라인 에러 |
| 5회 실패 | 계정 잠금 안내, 관리자 문의 메시지 |

---

## 컴포넌트 명세

| 요소 | 타입 | 비고 |
|------|------|------|
| 아이디 입력 | `<input type="email">` | 이메일 형식 검증 |
| 비밀번호 입력 | `<input type="password">` | 표시/숨김 토글 |
| 로그인 유지 | `<checkbox>` | 기본 OFF |
| 로그인 버튼 | Primary Button | 폼 submit, 로딩 스피너 |
