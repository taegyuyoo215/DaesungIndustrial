## 인터랙션 정의

| 요소 | 동작 |
|------|------|
| 보고서 유형 카드 클릭 | 해당 유형 설정 화면으로 전환 |
| [보고서 생성] 버튼 | 서버 API 호출, 진행 상태 표시 |
| 미리보기 | PDF 뷰어 (iframe) 또는 이미지 썸네일 |
| [다운로드] 버튼 | 파일 다운로드 트리거 |
| 최근 보고서 [다운로드] | 캐시된 파일 즉시 다운로드 |
