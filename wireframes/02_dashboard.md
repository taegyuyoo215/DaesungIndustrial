## 인터랙션 정의

| 요소 | 동작 |
|------|------|
| 요약 카드 (전체/정상/주의/경보) | 해당 상태로 카드 그리드 필터링 |
| 검색창 | 모터명/위치 실시간 검색 |
| 필터 버튼 | 라인별/공장별 필터 드롭다운 |
| 모터 카드 전체 클릭 | `/motors/[id]` 상세 페이지 이동 |
| 최근 알람 [전체보기] | `/alarms` 이동 |
| 알람 배너 (경보 발생 시) | 화면 상단 고정 배너 표시 |
