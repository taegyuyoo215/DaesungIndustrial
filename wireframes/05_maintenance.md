## 인터랙션 정의

| 요소 | 동작 |
|------|------|
| [+ 정비 기록 추가] | 정비 기록 추가 폼으로 이동 또는 모달 |
| 정비 행 [상세 보기▼] | 해당 행 확장 |
| [목록 뷰] / [캘린더 뷰] 탭 | 뷰 전환 |
| 캘린더 정비 예정 클릭 | 해당 정비 상세 표시 |
| 연결 알람 링크 | 알람 이력의 해당 알람으로 이동 |
